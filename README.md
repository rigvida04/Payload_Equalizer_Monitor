# Payload_Equalizer_Monitor

Static site reference for Payload Equalizer Monitor:
https://v0.app/chat/localhost-8080-oWq7NojCXLv?ref=LZS5J5

## Local run

Serve the repository root as static content:

```bash
python3 -m http.server 8080
```

Then open:

- `http://localhost:8080/`

## Deployment

This repository is configured for **GitHub Pages** via `.github/workflows/deploy-pages.yml`.
No Next.js runtime is required for this setup.
